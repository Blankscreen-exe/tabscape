# Theme: Synthwave

| | |
|---|---|
| **Look** | 80s outrun: purple night, twinkling stars, a striped sunset sun, a scrolling neon grid floor, a chrome-gradient clock. |
| **Decorations** | Sky gradient, 90 stars (random positions per tab), masked striped sun, perspective grid floor (CSS animation, stopped by reduced motion). |
| **Services** | None. |
| **Accent** | Neon pink. Role: lower half of the sun, grid floor, borders, glow, hovered links. Cyan (headings, search), sun yellow and the sky stay fixed (`--sw-cyan`, `--sw-yellow`). 4 presets. |
| **Variants requested** | None. |
| **Signature widgets** | None. Uses core `countdown` (weekend). |
| **Locked slots** | None. |
| **Origin** | `demos/synthwave.html`. The fake music player was dropped. |

## Quirks
- Grid rows 4–5 are left empty on purpose so the sun shows between the search bar and the lower widgets.
