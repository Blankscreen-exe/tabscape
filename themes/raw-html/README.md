# Theme: Raw HTML

| | |
|---|---|
| **Look** | Unstyled-web brutalism: white page, Times, blue underlined links (purple when visited), bordered "table cell" widgets, inset inputs, outset buttons. |
| **Decorations** | Header ("NEW TAB", last modified, `<hr>`) and footer address. |
| **Services** | None. |
| **Accent** | Link blue. Role: links and buttons. Black, white and the `#ffff00` highlighter stay fixed. 4 presets. |
| **Variants requested** | `links: list` (shown as a bulleted list). |
| **Signature widgets** | `counter` (visitor-style tab counter). |
| **Locked slots** | None. |
| **Origin** | `demos/brutalist/raw-html.html`. The demo's "show source" toggle was dropped. |
