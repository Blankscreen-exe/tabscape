# Theme: Template

Copy this folder to start a new theme. Keep this README up to date. It is the first thing to read when coming back to the theme years later.

| | |
|---|---|
| **Look** | One or two sentences. |
| **Decorations** | What `mount()` draws in the decor layer (canvas, marquee, sounds…). |
| **Services** | Events it listens to and what it stores in `ctx.state`. |
| **Variants requested** | e.g. `todo: quest-log` |
| **Signature widgets** | Widgets designed for this theme. |
| **Locked slots** | Layout items the user can't move, and why. |
| **Origin** | e.g. ported from `demos/variety/zen.html` |
