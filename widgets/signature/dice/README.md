# Widget: Feeling Lucky (dice)

| | |
|---|---|
| **What it does** | Roll a die to get a random site from a list you can edit in the settings. |
| **Shared data** | None. The site list is a per-instance setting. |
| **Events emitted** | None. |
| **Variants** | `default`. |
| **Best with** | `anti-design` (ported from `demos/brutalist/anti-design.html`). |

## Quirks
- The die face shows `pick % 6 + 1`, so lists longer than 6 still work. The face is just for fun.
