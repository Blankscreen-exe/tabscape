# Widget: System Info

| | |
|---|---|
| **What it does** | Session uptime (since the tab opened), viewport size, language, online/offline, plus an ASCII day-progress bar. |
| **Shared data** | None. |
| **Events emitted** | None. |
| **Variants** | `default`. |
| **Best with** | `terminal`, `mission-control` (ported from `demos/terminal.html`). |
