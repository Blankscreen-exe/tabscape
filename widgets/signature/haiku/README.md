# Widget: Haiku

| | |
|---|---|
| **What it does** | Shows one classical haiku (short English renderings), daily or per tab. |
| **Shared data** | None. |
| **Events emitted** | None. |
| **Variants** | `default`. |
| **Best with** | `zen` (ported from `demos/variety/zen.html`). |

## Quirks
- Poems live in `HAIKU` at the top of `widget.js`. Keep entries short, and attribute the poet.
