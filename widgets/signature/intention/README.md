# Widget: Intention

| | |
|---|---|
| **What it does** | One line for today's intention, autosaved. |
| **Shared data** | `{ text, date }` (`date` is local `YYYY-MM-DD` of the last edit). |
| **Events emitted** | None. |
| **Variants** | `default`. |
| **Best with** | `zen` (ported from `demos/variety/zen.html`). |

## Quirks
- With "Start blank each new day" on, yesterday's text is hidden (not deleted) until you type something new.
