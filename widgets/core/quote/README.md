# Widget: Quote

| | |
|---|---|
| **What it does** | Shows a quote, daily or per tab. The built-in list is in `QUOTES`; users can supply their own in the settings (`text — author` per line). |
| **Shared data** | None (own quotes are a per-instance setting). |
| **Events emitted** | None. |
| **Variants** | `default`. Themes style it with CSS (e.g. Paper & Ink's blockquote). |

## Quirks
- The author separator is ` — ` (space, em dash, space). The last occurrence on the line counts.
