# Widget: Progress

| | |
|---|---|
| **What it does** | Shows how much of the day, week (Monday start), month and year has passed. The almanac look also shows day of year and ISO week. |
| **Shared data** | None. |
| **Events emitted** | None. |
| **Variants** | `default` (number tiles + bars, Bento), `almanac` (label/value list, Paper & Ink). |

## Quirks
- `progress(date)` is exported and unit-tested (`dev/tests/widgets.test.mjs`).
